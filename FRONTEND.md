# CloudGaming - Полнофункциональный сайт для облачного геймнга

## 📋 Описание проекта

CloudGaming - это современный веб-сайт для облачного геймнга с полнофункциональным интерфейсом. Пользователи могут:
- 🎮 Запускать игры через браузер без установки
- 🌐 Играть на любых устройствах (ПК, планшет, смартфон)
- 💾 Экономить место на жестком диске
- 🎮 Использовать клавиатуру, мышь и геймпад для управления

## 🏗️ Структура проекта

```
frontend/
├── public/
│   └── index.html              # Основной HTML файл
├── src/
│   ├── components/
│   │   └── app.js              # Главный контроллер приложения
│   ├── services/
│   │   ├── api.js              # API клиент для взаимодействия с бэкенд
│   │   ├── webrtc.js           # Клиент WebRTC для видеопотока
│   │   ├── input.js            # Обработка попадающего ввода (клавиатура, мышь, геймпад)
│   │   └── notifications.js    # Система уведомлений
│   └── styles/
│       ├── main.css            # Основные стили
│       └── animations.css      # Анимации и переходы
```

## 🎨 Особенности дизайна

### Тёмная тема
- Удобна для длительного использования
- Приятные цвета с контрастными акцентами
- Красивые анимации и переходы

### Адаптивный дизайн
- Полная поддержка мобильных устройств

- Работает на экранах любого размера

### Современный интерфейс
- Использует HTML5 и CSS3

- Интуитивная навигация

## 📄 Экраны приложения

### 1. **Landing Page** (Главная страница)
- Красивое представление сервиса
- Демонстрация основных преимуществ
- Кнопки для входа и регистрации

### 2. **Auth Screen** (Экран аутентификации)
- Форма входа в аккаунт
- Форма регистрации нового аккаунта
- Валидация данных на клиенте

### 3. **Library Screen** (Библиотека игр)
- Сетка доступных игр
- Поиск по названию и описанию
- Информация об активных сессиях
- Пользовательское меню

### 4. **Stream Screen** (Экран потокового вещания)
- Видео с облачной игры
- Чат для общения
- Информация о подключении и статистике
- Параметры качества потока
- Выход из игры

## 🔧 Технические детали

### API Сервис (`api.js`)
Обрабатывает все запросы к бэкенду:
- Аутентификация (login, register, logout)
- Управление игровыми экземплярами
- WebRTC предложения/ответы
- Отправка входных команд
- Статистика потока

### WebRTC Клиент (`webrtc.js`)
- Установка соединения WebRTC
- Приём видеопотока
- Мониторинг статистики подключения
- Поддержка различных качеств потока

### Обработчик входа (`input.js`)
- Обработка событий клавиатуры
- Отслеживание движения мыши
- Поддержка геймпада
- Отправка команд на сервер

### Система уведомлений (`notifications.js`)
- Уведомления об успехе
- Уведомления об ошибках
- Уведомления предупреждения
- Автоматическое скрытие

## 🎮 Использование

### Для запуска приложения:
1. Убедитесь, что бэкенд запущен на `http://localhost:8000`
2. Откройте `frontend/public/index.html` в браузере
3. Зарегистрируйте новый аккаунт или войдите
4. Выберите игру для запуска
5. Наслаждайтесь облачным геймингом!

### Управление в игре:
- **Клавиатура**: Используйте все клавиши для управления
- **Мышь**: Движение и клики
- **Геймпад**: Полная поддержка для геймпадов
- **Escape**: Выход из игры

## 📊 Статистика подключения

В экране потокового вещания отображается:
- **Кадры в секунду** (FPS)
- **Битрейт** (Kbps)
- **Разрешение** экрана
- **Статус подключения** 🟢 (подключено) / 🔴 (отключено)

## 🎯 Параметры качества

Поддерживаются три уровня качества:
- **Низкое**: 1280x720, 2000 kbps (для мобильных и слабого интернета)
- **Среднее**: 1920x1080, 5000 kbps (рекомендуемое)
- **Высокое**: 3840x2160, 8000 kbps (для быстрого интернета)

## 🔐 Безопасность

- Токены хранятся в localStorage
- Заголовок Authorization для всех запросов
- Валидация на клиенте и сервере
- HTTPS поддержка
