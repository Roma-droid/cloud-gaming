### 3. Library Screen (Библиотека игр)

**Назначение**: Показ доступных игр и управление сессиями

**Компоненты**:
- **Header**:
  - Логотип приложения
  - Поле поиска по играм
  - Имя пользователя
  - Кнопка параметров
  - Кнопка выхода
- **Games Grid**:
  - Карточки игр с эмодзи/изображениями
  - Информация на карточке (название, описание, жанр, кол-во игроков)
  - Интерактивные карточки с кнопкой Play по hovering
  - Поиск в реальном времени
- **Active Sessions**:
  - Список активных сессий

### 4. Stream Screen (Экран потокового вещания)

**Назначение**: Отображение видеопотока игры и управление

**Компоненты**:
- **Stream Header**:
  - Название игры
  - Кнопка параметров (⚙️)
  - Кнопка полного экрана (⛶)
  - Кнопка выхода (красная)
- **Stream Content**:
  - Видео элемент (основная часть)
  - Информация о подключении (статус, FPS, bitrate)
  - Подсказки управления
- **Stream Chat**:
  - История сообщений
  - Поле ввода сообщения
- **Stream Overlays**:
  - Loading overlay (во время запуска)
  - Error overlay (при ошибках подключения)

**Функциональность**:

## ✨ Анимации

### Основные анимации
- **fadeIn**: Затухание на входе
- **slideIn**: Скольжение слева при появлении
- **slideUp**: Скольжение снизу
- **bounce**: Отскок при клике
- **float**: Плавание в воздухе
- **pulseGreen**: Пульсирование зелёной точки

### Переходы
- Fast: 150ms
- Base: 300ms
- Slow: 500ms

## 🔧 Расширение функциональности

### Добавление новой кнопки
1. Используйте класс `btn` и модификатор (`btn-primary`, `btn-secondary`)
2. Добавьте обработчик события в `app.js`
3. Реализуйте функцию в соответствующем сервисе

### Добавление новой страницы
1. Создайте HTML структуру в `index.html`
2. Добавьте стили в `main.css` или `animations.css`
3. Добавьте функции в `app.js` для навигации

### Добавление нового API запроса
1. Создайте функцию в `api.js`
2. Используйте в нужном месте приложения
3. Обработайте ошибки с `notificationManager`
